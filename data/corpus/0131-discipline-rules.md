# 学生违纪处分管理规定

> 依据教育部《普通高等学校学生管理规定》制定。考试类违纪的事实认定
> 按《考试违规违纪处理办法》执行；宿舍类违规按《学生宿舍管理规定》
> 认定。

## 一、处分种类

警告、严重警告、记过、留校察看、开除学籍。

## 二、违纪情形与量纪

| 情形 | 处分档次 |
|------|----------|
| 扰乱课堂/公共秩序，情节轻 | 警告 |
| 旷课情节严重、屡次晚归不改 | 警告至严重警告（考勤口径见《本科生课堂考勤管理规定》） |
| 冒用他人证件、转借学生证校园卡 | 警告至记过 |
| 考试违纪（未构成作弊） | 严重警告或记过 |
| 考试作弊 | 留校察看（组织作弊、二次作弊、替考：开除学籍） |
| 盗窃、诈骗、故意损坏公私财物 | 记过至留校察看 |
| 打架斗殴、寻衅滋事 | 记过至开除学籍 |
| 违规用电引发火情 | 严重警告至记过（宿舍口径见《学生宿舍管理规定》） |
| 受治安管理处罚 | 视情节记过至开除学籍 |
| 触犯刑法 | 开除学籍 |
| 论文代写买卖、学术不端 | 按作弊处理（详见专项规定） |

## 三、处分程序

1. **调查**：学生工作部或学院调查取证（询问笔录、材料核验），学生
   有陈述申辩权（处理决定前须告知拟处分事实与依据）。
2. **决定**：警告至留校察看由学生工作部研究决定；开除学籍由校长
   办公会议研究决定。
3. **送达**：处分决定书送达本人（拒收的留置送达），并通知家长。
4. **申诉**：学生可在收到决定书 10 个工作日内向学生申诉委员会
   申诉（详见《学生申诉处理办法》）；申诉期间不停止处分执行。

## 四、处分影响

1. 处分期内不得参评奖学金与评优、不得申请转专业与国际交换、不得
  担任学生干部。
2. 因作弊受处分的，按《考试违规违纪处理办法》取消该次学位授予
   申请资格。
3. 处分材料归入学生档案（见《在校生档案管理办法》）。

## 五、处分解除

1. 处分期：警告、严重警告 6 个月；记过 12 个月；留校察看 12 个月。
2. 期满按《学生违纪处分解除实施细则》申请解除；解除后恢复参评
   资格，处分材料留存档案但不作为后续评价的加重依据。
3. 毕业前处分期未满的，不予解除（考察表现可记载于鉴定表）。

## 附则

本规定自 2026 年 3 月起施行，由学生工作部负责解释。
