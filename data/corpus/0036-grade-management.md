# 本科生成绩管理办法

## 成绩记载方式

1. 课程成绩以百分制记载为主；部分课程（认定课程、部分实践环节）按"通过/
   不通过"二值记载。
2. 毕业论文（设计）成绩按优秀、良好、中等、及格、不及格五级记载（详见
   《本科毕业论文（设计）管理规定》）。
3. "通过/不通过"记载的课程不参与 GPA 计算。

## 百分制成绩与绩点对照表

| 百分制 | 绩点 | 等级 |
|--------|------|------|
| 90—100 | 4.0 | 优秀 |
| 85—89 | 3.7 | |
| 82—84 | 3.3 | |
| 78—81 | 3.0 | |
| 75—77 | 2.7 | |
| 72—74 | 2.3 | |
| 68—71 | 2.0 | |
| 64—67 | 1.5 | |
| 60—63 | 1.0 | 及格 |
| <60 | 0 | 不及格 |

绩点保留 1 位小数。平均学分绩点（GPA）= Σ（课程绩点 × 课程学分）/ Σ
课程学分，计算范围以培养方案内课程为准。

## 成绩构成与录入

1. 课程总评成绩=平时成绩+期末成绩，期末占比一般为 50%—70%，具体以教学
   大纲公布为准。
2. 任课教师须在考试结束后 5 个工作日内完成成绩录入并提交。
3. 成绩提交后不得随意更改；确需更改的（录入错误、漏判等），由任课教师
   提交书面说明，经开课学院与教务处审批后由教务处更正并留痕。

## GPA 的应用口径

1. 转专业申请：GPA ≥ 3.0（《本科生转专业管理办法（2026 年修订）》）。
2. 国际交换申请：GPA ≥ 3.2（《本科生国际交换生项目选派办法》）。
3. 辅修申请：GPA ≥ 2.8（《辅修专业管理办法》）。
4. 保研综合评价：GPA 折算成绩占 90%（《推荐免试研究生实施细则》）。
5. 奖学金评定按排名比例（前 10%/5%/15%/30%），不以 GPA 绝对值为线。

## 附则

本办法自 2026 年 3 月起施行，由教务处负责解释。成绩复查与复核流程见
《成绩复查与复核办理指南》。
