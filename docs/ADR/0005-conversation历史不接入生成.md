# ADR-0005 conversation：历史不接入答案生成

日期：2026-09-04　状态：已采纳（P2）

## 背景

conversation 服务落库每轮消息（审计/前端展示），并预留「上下文组装 API」。
是否把历史拼进答案生成的 prompt？

## 决策

**默认不接入**。冻结单体的行为是各轮独立作答（唯一跨轮状态是办理流程的
slots/phase）；接入历史会改变每轮答案内容，26 题评测（尤其 factual 关键词
命中与引用召回）大概率回归。消息落库只做审计，Recall/Put（P5 记忆 API）
同样不接入生成。

## 后果

- 迁移期间行为与单体逐字对齐；接入历史属于行为变更，迁移完成后单独评估
  （需新增多轮评测用例先行）。
- PARITY-MS #12 备案。
