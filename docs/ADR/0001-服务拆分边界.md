# ADR-0001 服务拆分边界：1 网关 + 5 gRPC 服务

日期：2026-09-04　状态：已采纳（P0 起）

## 背景

冻结单体（tag go-monolith）的 `cmd/server` + `internal/*` 需升级为微服务部署，
行为不变（PARITY.md + 26 题评测为验收）。

## 决策

| 服务 | 职责边界 | 归属的冻结包 |
| --- | --- | --- |
| gateway | 对外 HTTP/SSE 唯一入口：限流、CORS、身份派生、`/api/*`、`/admin/*` | internal/middleware（限流） |
| orchestrator | 编排管线、五分类路由、工具调度、agent_config | internal/agent（拷贝改造） |
| conversation | 办理会话状态（TTL 语义）+ 消息审计 | internal/agent/session.go（拷贝） |
| generate | LLM 网关 + 预算集中计量 | internal/llm + internal/budget（拷贝/新实现） |
| tool | 权限矩阵 + mock 业务系统 | internal/agent/tools.go + internal/business（拷贝） |
| rag | 混合检索 + 摄入流水线 + 记忆 | internal/rag（import 共享为主） |

边界原则：**行为锚点在哪个包，服务就归谁**；纯函数（dates/config）全共享；
编排管线因依赖注入形态巨变采用拷贝改造（SERVICES.md §2）。

## 后果

- internal/ 冻结只读，改动逐条记录：LLMer 接口化 + Rewriter 导出 +
  EmbedBatched 接口化 + BM25Index 提取（均在 internal/rag，行为零变化，
  单体测试全绿佐证）。
- 单体 cmd/server 保留为 A/B 对照与回退入口。
