# ADR-0007 预算的分布式计量

日期：2026-09-04　状态：已采纳（P1 计量集中 / P2 PG 持久化）

## 决策

- 每日 token 预算的**计量与判定集中在 generate**（所有 LLM/embedding 调用
  的必经之路）：调用前预检（耗尽 → RESOURCE_EXHAUSTED，文案逐字）+ 事后
  入账（非流式按 usage.total_tokens；流式按产出字符/2 下限 1，中断也入账；
  embedding 按 usage 缺省文本长度/2）。
- orchestrator 在 chat 入口经 `EnsureBudget` 预检（耗尽 → HTTP 429，发生在
  写 SSE 头之前，与单体一致）。
- 持久化：PG `budget_usage(date PK, tokens)`，UTC 日期为键写穿，跨重启累计
  （对齐单体 usage.json 语义）；DSN 未配置降级内存（重启清零，告警可见）。

## 后果

- 单实例 generate 下进程内 mutex 即原子；多实例需改 Redis INCRBY 或 PG
  行锁（当前部署形态不需要，预留）。
- 单体的 `data/usage.json` 不再被微服务更新（PARITY-MS #3）。
