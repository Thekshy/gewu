# ADR-0004 generate：重试与降级策略

日期：2026-09-04　状态：已采纳（P1）

## 决策

- **降级决策留在调用方**：generate 只如实报错（超时/网络/HTTP 错误原样上抛），
  由 orchestrator/rag 按冻结单体的语义各自降级（路由→启发式；改写→原查询；
  向量路→纯 BM25；抽槽→启发式）。
- **重试**：仅「连接失败且请求未发出」（TCP 拨号阶段失败，`net.OpError.Op
  == "dial"`）重试 1 次，且只对非流式请求；流式一律不重试——重放已产出的
  部分增量会改变事件流形状（降级链路与延迟变形）。
- 预算耗尽 → RESOURCE_EXHAUSTED（中文文案逐字）；无 key → FAILED_PRECONDITION
  （文案逐字）。中途断开：已产出部分入账（字符/2 下限 1），错误原样透传
  （回调错误不包装——与单体一致）。

## 后果

- 单体重试为零，微服务多了拨号级 1 次重试：只影响「端点瞬时不可达」的
  故障路径，正常路径零差异（PARITY-MS #8）。
