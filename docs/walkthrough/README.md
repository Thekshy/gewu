> **历史版本注记（P14）**：本系列讲解的代码形态为 **Go 单体**（git tag `go-final`
> 可逐篇对照源码）。P14 起编排层已迁 Python + LangGraph（ADR-0010），但设计决策

## 阅读顺序建议

- 想快速理解系统：01 → 02 → 03；
- 想看工程化程度：06 → 07；
- 想看设计推演与扩展路径：04 → 05 → 11；
- 想看存储与可靠性设计：08 → 09；
- 想看检索语料的上游（Word/PDF/Excel/图片怎么进库）：10。

每篇末尾都有「边界与已知短板」——写清楚自己没做什么、为什么现阶段不做，
和做了什么同样是设计的一部分。
